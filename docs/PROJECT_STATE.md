- 2026-11-04：价格位置补上长期指标：近 3 / 5 年年化、近 3 年最大回撤、回撤后是否修复；样本不足按 80% 覆盖率门槛留空，不拿短样本年化冒充长期收益。负数年化与「大回撤且未修复」进入个股风险清单；个股详情页同步展示。
- 2026-11-04：代码查询新增「历史条件收益」：取当前一年价格分位 ±10 个百分点的历史样本，统计之后 1 年 / 3 年的中位数、四分位与上涨占比；样本少于 20 个时只说明原因，不给数字。决策卡新增对应区块，prompt 升到 `code-lookup-v2-prompt-3`，AI 引用时必须带样本数并说明不保证。
- 2026-11-04：代码查询决策卡新增「本标的长期趋势」：近 3 / 5 年年化、近 3 年最大回撤及是否修复；长期走平或向下单独成标签，3 年与 5 年方向不一致标为 `MIXED`。样本不足（不足 3 年 / 5 年日历跨度）时留空并说明。
- 2026-11-04：筛选默认每档从 3 只调到 5 只，与扩池/换一批配合；`perBucket` 仍可显式覆盖。
- 2026-11-04：ETF 目录补齐：新增每日 `DAILY_ETF_CATALOG`，从新浪行情中心 `etf_hq_fund` 分页拉取沪深全部挂牌 ETF（实测 1717 只）写入 `md_instrument`；只补新不覆盖已有行，指数池的跟踪指数与别名不受影响。新增探针 `automation/scripts/verify_etf_catalog.py` 钉住分页上限、双市场与计数覆盖率；部署后可先跑 `python automation/scripts/warehouse_sync.py --etf-catalog` 立即补库，不必等 17:00。
